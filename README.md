🏧 ATM Machine

A simple ATM Machine project using Python created as part of my Python learning journey.

This project demonstrates basic Python concepts such as variables, input/output, conditions, loops, and arithmetic operations.

📌 Features

- 🔐 Set a 4-digit PIN
- 💰 Withdraw money
- 💵 Deposit money
- 💳 Check account balance
- 🔑 Update PIN
- 🚪 Exit the ATM
- ⚠️ Handles incorrect PIN and invalid menu choices

🛠️ Technologies Used

- Python 3
- "if-elif-else"
- "for" loop
- Variables
- User input
- Arithmetic operators

💳 ATM Menu

▶️ How to Run

1. Make sure Python 3 is installed.
2. Clone this repository:

git clone https://github.com/Deepika-V-D/ATM-machine.git

3. Open the project folder.
4. Run the Python file:

python atm.py
